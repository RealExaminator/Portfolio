# My Portfolio

A single-page portfolio for job applications. It introduces me shortly, shows some projects I've done, and links to email, LinkedIn, and GitHub.

## Run locally

```bash
npm install
npm run dev
```

The site opens at http://localhost:5173.

## Live site

GitHub Pages publishes the production build at https://realexaminator.github.io/Portfolio/. Pushing to `main` runs the Pages workflow.
