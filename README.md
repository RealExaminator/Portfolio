# Ikenna Ihetu — portfolio

A single-page portfolio for job applications. It introduces Ikenna, shows three projects, and links to email, LinkedIn, and GitHub.

## Run locally

```bash
npm install
npm run dev
```

The site opens at http://localhost:5173.

## Live site

GitHub Pages publishes the production build at https://realexminator.github.io/Portfolio/. Pushing to `main` runs the Pages workflow.
